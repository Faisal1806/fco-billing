# Firebase Studio

This is a NextJS starter in Firebase Studio.

To get started, take a look at src/app/page.tsx.

## Enabling Firestore

If you see an error like "Service firestore is not available", you need to enable it in the Firebase Console.

1.  Go to the [Firebase Console](https://console.firebase.google.com/).
2.  Select your project (`swiftsale-ewd7o`).
3.  In the left-hand navigation under "Build", click on **Firestore Database**.
4.  Click the **Create database** button.
5.  Choose to start in **production mode** or **test mode**.
6.  Select a location for your database.
7.  Click **Enable**.
