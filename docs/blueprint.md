# **App Name**: SwiftSale

## Core Features:

- Sales Logging: Record sales transactions (POS, Invoices, Wholesale Orders) quickly and easily.
- Product Catalog: Browse and manage a streamlined list of product details.
- Quick Analytics: Display essential data for recent sales.
- Contextual Help Tool: LLM tool dynamically providing advice regarding possible actions depending on context and situation, within the app, in order to support users of all levels.
- Invoice Generation: Create and export invoices for sales transactions.
- Language Switch: Switch the User Interface text between English and Urdu.

## Style Guidelines:

- Primary color: Soft lavender (#D0BFFF) for a sense of calm and efficiency.
- Background color: Very light lavender (#F5F0FF).
- Accent color: Light sky blue (#ADD8E6) for interactive elements.
- Body and headline font: 'Inter', a sans-serif for clean and modern readability.
- Use simple, outline-style icons for key functions.
- Clean, card-based layouts to group related functions intuitively.
